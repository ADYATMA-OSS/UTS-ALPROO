Deskripsi Singkat Aplikasi

Aplikasi ini dikembangkan dalam bahasa C++ untuk memenuhi kebutuhan operasional kasir laundry kiloan modern. Sistem bekerja secara interaktif pada antarmuka terminal/console dengan kemampuan memproses transaksi berulang tanpa batasan jumlah pelanggan, memvalidasi masukan data secara ketat, menerapkan pembulatan berat ke atas (minimum 2 kg), menghitung potongan diskon keanggotaan, serta menyajikan rekapitulasi performa harian secara komprehensif.

Kepatuhan Batasan Proyek: Program disusun murni menggunakan konsep dasar pemrograman terstruktur (variabel, konstanta, operator aritmetika/logika/relasional, percabangan if-else bertingkat, dan perulangan do-while/while) tanpa ketergantungan pada struktur data array, objek/OOP kompleks, maupun database eksternal.

Latar Belakang, Tujuan, & Pengguna

Masalah Nyata

Perhitungan manual sering menimbulkan ketidakkonsistenan pembulatan berat timbangan desimal, kekeliruan perhitungan diskon bertingkat, serta kesalahan rekonsiliasi kas harian laundry.

Tujuan Program

Mengotomatisasi kalkulasi tagihan pelanggan secara presisi dan menghasilkan laporan audit rekapitulasi harian yang akurat bagi pemilik usaha laundry.

Pengguna Sistem

Kasir atau staf operasional laundry yang bertugas menimbang cucian masuk dan mencetak struk rincian tagihan kepada konsumen.

Ketentuan Bisnis & Batasan Kasus

Tarif Layanan Dasar

• Reguler: Rp7.000 / kg
• Express: Rp11.000 / kg

Aturan Pembulatan Berat

• Berat pecahan dibulatkan ke atas (ceil)
• Berat < 2.0 kg tetap dihitung minimum 2.0 kg

Ketentuan Diskon Bertingkat

• Member ($\ge 5\text{ kg}$): Diskon 5%
• Non-Member ($\ge 10\text{ kg}$): Diskon 3%
• Lainnya: Diskon 0%

Layanan Antar

• Biaya flat: Rp8.000
• Catatan: Tidak termasuk komponen yang memperoleh potongan diskon!

3. Modul A (Proses Utama)

Selesai & Teruji

Penanggung Jawab: Anggota 1

Lead Programmer Modul A

Modul A berfokus pada alur pemrosesan transaksi per pelanggan: menerima input nama, berat, paket layanan, status member, dan opsi antar; memvalidasi keabsahan data; mengkalkulasi pembulatan ke atas; menentukan diskon dan biaya antar; hingga mencetak struk rincian tagihan secara visual.

Algoritma Deskriptif Modul A

  1. Inisialisasi konstanta tarif (Reguler = 7000, Express = 11000, Antar = 8000) dan batas syarat diskon.
  2. Mulai perulangan transaksi dengan menaikkan nomor transaksi counterTransaksi.
  3. Minta input namaPelanggan.
  4. Validasi Berat: Minta input beratCucian. Jika bernilai ≤ 0 atau non-numerik, beri peringatan dan ulangi hingga valid.
  5. Validasi Layanan: Tampilkan menu 1 (Reguler) dan 2 (Express). Jika input bukan 1 atau 2, ulangi hingga valid.
  6. Validasi Member: Tanyakan apakah pelanggan adalah member (Y/T). Validasi input.
  7. Validasi Antar: Tanyakan apakah menggunakan fasilitas antar (Y/T). Validasi input.
  8. Lakukan pembulatan ke atas: beratBulat = ceil(beratCucian). Jika beratBulat < 2.0, maka beratHitung = 2.0; jika tidak, beratHitung = beratBulat.
  9. Tentukan tarif layanan berdasarkan paket yang dipilih.
  10. Hitung subtotal cucian: subtotalCuci = beratHitung * tarifPerKg.
  11. Evaluasi diskon: Jika member dan berat $\ge 5$ kg, diskon 5%; jika non-member dan berat $\ge 10$ kg, diskon 3%; jika tidak, diskon 0%.
  12. Tentukan biaya antar: Rp8.000 jika memilih antar, atau Rp0 jika tidak.
  13. Hitung total tagihan: totalTagihan = (subtotalCuci - nilaiDiskon) + biayaAntar.
  14. Tampilkan struk rincian tagihan dengan rapi ke layar terminal.
  15. Tanyakan apakah ingin memproses transaksi pelanggan lain (Y/T). Jika 'Y', ulangi ke langkah 2; jika 'T', program selesai.

Pseudocode Modul A

PSEUDOCODE - MODUL_A 
PROGRAM ModulA_ProsesUtama
DEKLARASI
    namaPelanggan : string
    beratCucian, beratBulat, beratHitung, tarifPerKg : real
    subtotalCuci, persenDiskon, nilaiDiskon, biayaAntar, totalTagihan : real
    jenisLayanan, counterTransaksi : integer
    statusMember, layananAntar, ulang : character

ALGORITMA
    counterTransaksi <- 0
    DO
        counterTransaksi <- counterTransaksi + 1
        INPUT namaPelanggan
        
        REPEAT
            INPUT beratCucian
        UNTIL beratCucian > 0

        REPEAT
            INPUT jenisLayanan
        UNTIL jenisLayanan == 1 OR jenisLayanan == 2

        REPEAT
            INPUT statusMember
            statusMember <- UPPERCASE(statusMember)
        UNTIL statusMember == 'Y' OR statusMember == 'T'

        REPEAT
            INPUT layananAntar
            layananAntar <- UPPERCASE(layananAntar)
        UNTIL layananAntar == 'Y' OR layananAntar == 'T'

        // Perhitungan Pembulatan & Batas Minimum
        beratBulat <- CEIL(beratCucian)
        IF beratBulat < 2.0 THEN
            beratHitung <- 2.0
        ELSE
            beratHitung <- beratBulat
        ENDIF

        // Penentuan Tarif
        IF jenisLayanan == 1 THEN
            tarifPerKg <- 7000.0
        ELSE
            tarifPerKg <- 11000.0
        ENDIF

        subtotalCuci <- beratHitung * tarifPerKg

        // Penentuan Diskon
        IF statusMember == 'Y' AND beratHitung >= 5.0 THEN
            nilaiDiskon <- subtotalCuci * 0.05
        ELSE IF statusMember == 'T' AND beratHitung >= 10.0 THEN
            nilaiDiskon <- subtotalCuci * 0.03
        ELSE
            nilaiDiskon <- 0.0
        ENDIF

        // Biaya Antar
        IF layananAntar == 'Y' THEN
            biayaAntar <- 8000.0
        ELSE
            biayaAntar <- 0.0
        ENDIF

        totalTagihan <- (subtotalCuci - nilaiDiskon) + biayaAntar

        OUTPUT RincianTagihan(counterTransaksi, namaPelanggan, beratCucian, beratHitung, subtotalCuci, nilaiDiskon, biayaAntar, totalTagihan)

        REPEAT
            INPUT ulang
            ulang <- UPPERCASE(ulang)
        UNTIL ulang == 'Y' OR ulang == 'T'

    WHILE ulang == 'Y'
END PROGRAM

Source Code C++ Modul A

File tersimpan pada src/modul_a.cpp. Dilengkapi validasi buffer cin.clear() untuk mencegah crash saat menerima input non-angka.

src/modul_a.cpp 
#include <iostream>
#include <iomanip>
#include <string>
#include <cmath>
#include <limits>

using namespace std;

// Definisi Konstanta Tarif dan Batasan
const double TARIF_REGULER           = 7000.0;
const double TARIF_EXPRESS           = 11000.0;
const double BIAYA_ANTAR             = 8000.0;
const double MIN_BERAT               = 2.0;
const double MIN_BERAT_MEMBER_DISKON = 5.0;
const double MIN_BERAT_NON_DISKON    = 10.0;
const double PERSEN_DISKON_MEMBER    = 0.05;
const double PERSEN_DISKON_NON       = 0.03;

int main() {
    string namaPelanggan;
    double beratCucian = 0.0;
    int jenisLayanan = 0;
    char statusMember = 'N', layananAntar = 'N', ulang = 'T';

    double beratBulat = 0.0, beratHitung = 0.0, tarifPerKg = 0.0;
    string namaLayanan = "";
    double subtotalCuci = 0.0, persenDiskonTampil = 0.0, nilaiDiskon = 0.0;
    double biayaAntar = 0.0, totalTagihan = 0.0;
    int counterTransaksi = 0;

    do {
        counterTransaksi++;
        cout << "\n[TRANSAKSI #" << counterTransaksi << "]\n";
        cout << "Masukkan Nama Pelanggan        : ";
        getline(cin >> ws, namaPelanggan);

        // Validasi Berat Cucian
        while (true) {
            cout << "Masukkan Berat Cucian (kg)     : ";
            if (cin >> beratCucian) {
                if (beratCucian > 0.0) break;
                cout << "  [ERROR] Berat cucian harus > 0 kg!\n";
            } else {
                cout << "  [ERROR] Masukan harus angka numerik valid!\n";
                cin.clear();
                cin.ignore(numeric_limits<streamsize>::max(), '\n');
            }
        }

        // Validasi Jenis Layanan
        while (true) {
            cout << "Pilih Jenis Layanan (1. Reguler / 2. Express): ";
            if (cin >> jenisLayanan) {
                if (jenisLayanan == 1 || jenisLayanan == 2) break;
                cout << "  [ERROR] Masukkan angka 1 atau 2!\n";
            } else {
                cin.clear();
                cin.ignore(numeric_limits<streamsize>::max(), '\n');
            }
        }

        // Validasi Status Member
        while (true) {
            cout << "Kartu Member? (Y/T)            : ";
            cin >> statusMember;
            statusMember = toupper(statusMember);
            if (statusMember == 'Y') break;
            else if (statusMember == 'T' || statusMember == 'N') { statusMember = 'T'; break; }
            cout << "  [ERROR] Masukkan Y atau T!\n";
        }

        // Validasi Layanan Antar
        while (true) {
            cout << "Layanan Antar (+Rp8.000)? (Y/T): ";
            cin >> layananAntar;
            layananAntar = toupper(layananAntar);
            if (layananAntar == 'Y') break;
            else if (layananAntar == 'T' || layananAntar == 'N') { layananAntar = 'T'; break; }
            cout << "  [ERROR] Masukkan Y atau T!\n";
        }

        // Kalkulasi
        beratBulat = ceil(beratCucian);
        beratHitung = (beratBulat < MIN_BERAT) ? MIN_BERAT : beratBulat;
        tarifPerKg = (jenisLayanan == 1) ? TARIF_REGULER : TARIF_EXPRESS;
        namaLayanan = (jenisLayanan == 1) ? "Reguler" : "Express";
        subtotalCuci = beratHitung * tarifPerKg;

        if (statusMember == 'Y' && beratHitung >= MIN_BERAT_MEMBER_DISKON) {
            persenDiskonTampil = 5.0;
            nilaiDiskon = subtotalCuci * PERSEN_DISKON_MEMBER;
        } else if (statusMember == 'T' && beratHitung >= MIN_BERAT_NON_DISKON) {
            persenDiskonTampil = 3.0;
            nilaiDiskon = subtotalCuci * PERSEN_DISKON_NON;
        } else {
            persenDiskonTampil = 0.0;
            nilaiDiskon = 0.0;
        }

        biayaAntar = (layananAntar == 'Y') ? BIAYA_ANTAR : 0.0;
        totalTagihan = (subtotalCuci - nilaiDiskon) + biayaAntar;

        // Cetak Struk
        cout << "\n=================================================================\n";
        cout << "                    RINCIAN TAGIHAN LAUNDRY                      \n";
        cout << "=================================================================\n";
        cout << left << setw(30) << "Nama Pelanggan"          << ": " << namaPelanggan << "\n";
        cout << left << setw(30) << "Status Member"           << ": " << (statusMember == 'Y' ? "Member" : "Non-Member") << "\n";
        cout << left << setw(30) << "Paket Layanan"           << ": " << namaLayanan << "\n";
        cout << fixed << setprecision(2);
        cout << left << setw(30) << "Berat Aktual"            << ": " << beratCucian << " kg\n";
        cout << fixed << setprecision(0);
        cout << left << setw(30) << "Berat Dihitung (Aturan)" << ": " << beratHitung << " kg\n";
        cout << left << setw(30) << "Tarif per Kilogram"      << ": Rp " << tarifPerKg << "\n";
        cout << "-----------------------------------------------------------------\n";
        cout << left << setw(30) << "Subtotal Biaya Cucian"   << ": Rp " << subtotalCuci << "\n";
        string strDiskon = "Potongan Diskon (" + to_string((int)persenDiskonTampil) + "%)";
        cout << left << setw(30) << strDiskon                 << ": -Rp " << nilaiDiskon << "\n";
        cout << left << setw(30) << "Biaya Layanan Antar"     << ": Rp " << biayaAntar << "\n";
        cout << "-----------------------------------------------------------------\n";
        cout << left << setw(30) << "TOTAL PEMBAYARAN"        << ": Rp " << totalTagihan << "\n";
        cout << "=================================================================\n\n";

        cout << "Proses pelanggan lain? (Y/T): ";
        cin >> ulang;
        ulang = toupper(ulang);
    } while (ulang == 'Y');

    return 0;
}
